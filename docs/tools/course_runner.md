# 🖥️ Course CLI Runner

An interactive terminal dashboard for exploring lessons, taking quizzes, and running tests.

---

## How to Run

```bash
python course_runner.py
```

## Commands

| Command | Description |
|---|---|
| `python course_runner.py` | Open the interactive menu |
| `python course_runner.py --list-weeks` | Browse all weeks & lessons |
| `python course_runner.py --status` | View progress metrics |
| `python course_runner.py --run-lesson 004` | Execute a specific lesson |
| `python course_runner.py --quiz week01` | Take a topic quiz |
| `python course_runner.py --test-all` | Run the full test suite |

## Features

- 📋 **Lesson browser** — browse and run any lesson script
- 🧪 **Quiz system** — test your knowledge per week
- 📊 **Progress metrics** — see how far you've come
- 🧪 **Test runner** — run automated tests across all modules
- 🎨 **Colored output** — beautiful terminal UI with ANSI colors
