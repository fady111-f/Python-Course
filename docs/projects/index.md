# 🚀 Mini Projects

One hands-on project for every **5 videos watched**, reinforcing concepts through practice.

---

## Available Projects

| # | Project | Videos | Concepts |
|---|---|---|---|
| 01 | [Personal Card Generator](01_personal_card_generator.md) | 1–5 | `print()`, variables, data types |
| 02 | [Mad Libs Game](02_mad_libs_game.md) | 6–10 | Variables, escape sequences, concatenation |
| 03 | [Text Analyzer](03_text_analyzer.md) | 11–15 | String methods, indexing, slicing |

---

## How to Run

Each project lives in the `projects/` directory:

```bash
cd projects/01_personal_card_generator
python main.py
```

---

## Philosophy

> **Every 5 videos = 1 project**

These projects are designed to:

1. **Apply** the exact concepts from the videos you just watched
2. **Build** something tangible you can show off
3. **Reinforce** learning through hands-on practice
4. **Stay fun** — no boring exercises, only real programs!

As you progress through the course, new projects will be added automatically.
