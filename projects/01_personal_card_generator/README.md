# 🎴 Personal Card Generator

**Concepts Used**: `print()`, variables, data types, string concatenation

## What It Does

Generates a beautifully styled personal information card directly in your terminal using only basic Python concepts.

## How to Run

```bash
python main.py
```

## Customize It!

Edit the variables at the top of `main.py` to create your own card:

```python
first_name = "Your Name"
job_title = "Your Title"
# ...etc
```
