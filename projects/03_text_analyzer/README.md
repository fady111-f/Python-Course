# 📊 Text Analyzer

**Concepts Used**: String methods, indexing, slicing, `input()`, `len()`, `.find()`, `.count()`, `.upper()`, `.lower()`, `.split()`

## What It Does

A powerful text analysis tool that breaks down any input text into detailed statistics:
- Character counts & case analysis
- Case transformations (upper, lower, title, swap)
- Slicing showcase (first/last chars, reversed, every 2nd char)
- Search & find functionality
- Character frequency chart with visual bars
- Word analysis (longest, shortest, first, last)

## How to Run

```bash
python main.py
```
